Features

特性

Zero install for guests

Android, iOS, tablets, another computer — anything with a browser. The host runs the service; guests just open the page.

访客零安装

安卓 / iOS / 平板 / 另一台电脑，有浏览器就行。服务跑在主机上，访客打开网页即可。

Two-way transfer

Phone uploads to the computer; the computer drops files into the outbox for the phone to pick up. Original names kept, never renamed.

双向传输

手机传电脑、电脑发手机（发件箱拖入即发）。文件按原名保存，不改名不压缩。

Clipboard, both directions

Two independent opt-in switches. Reading the host's clipboard is off by default — clipboards hold secrets.

双向剪贴板

两个方向独立开关。读取主机剪贴板默认关闭 —— 剪贴板里常有密码。

Bilingual UI & guides

Chinese / English switchable in the app and on every page of both user guides.

中英双语

应用内一键切换中英，两份使用手册全双语。

Cross-platform host

macOS menu bar app included; Windows & Linux run the same zero-dependency Python server.

主机跨平台

macOS 菜单栏应用；Windows / Linux 跑同一个零依赖 Python 服务。

Private by design

No cloud, no account, no telemetry — traffic never leaves your router. Optional access token for public Wi-Fi.

隐私优先

无云、无账号、无遥测 —— 流量不出路由器。公共 Wi-Fi 可开访问口令。

Quick Start

快速开始

  1. Start the host — macOS: open the app; Windows / Linux: ./scripts/start.sh or start.bat (Python 3.8+, no dependencies).
  2. 启动主机 —— macOS 打开应用；Windows / Linux 运行 ./scripts/start.sh 或 start.bat（需 Python 3.8+，零依赖）。
  3. Show the QR code — menu bar icon or the local console at http://127.0.0.1:8765/.
  4. 显示二维码 —— 菜单栏图标，或本机控制台 http://127.0.0.1:8765/。
  5. Scan & go — phone on the same Wi-Fi scans the code; files and text flow both ways.
  6. 扫码即用 —— 手机连同一 Wi-Fi 扫码，文件文字双向直传。

⚠️ Designed for trusted local networks only (plain HTTP by design). On public Wi-Fi, enable the access token: TOKEN=auto. For cross-network use, bring your own tunnel (e.g. Tailscale).

⚠️ 仅限可信局域网使用（明文 HTTP 是刻意设计）。公共 Wi-Fi 请开启口令 TOKEN=auto；跨网段请自备隧道（如 Tailscale）。
